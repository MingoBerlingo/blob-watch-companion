# Sensors Layer

This folder contains sensor drivers grouped by chip.

Use the chip-specific READMEs directly:

- [imu_qmi8658/README.md](imu_qmi8658/README.md): QMI8658 IMU driver
- [touch_cst816s/README.md](touch_cst816s/README.md): CST816S touch driver

The board-level transport (I2C/SPI primitives) is provided by [../board/README.md](../board/README.md).
